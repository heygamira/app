Latest session, by modality

Not on the network

Restart with --phone to serve the apps to this network over https, with addresses and QR codes here:

python run.py --phone

https is what makes the microphone work on a phone — browsers only hand a page the mic on a secure origin. The certificate is self-signed and generated on this machine, so the phone asks once before trusting it. The Gemini token server stays on localhost either way; the phone reaches it through the app's own address, so the API key never goes on the network.
